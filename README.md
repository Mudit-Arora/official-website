# Official website

Source for [muditarora.vercel.app](https://muditarora.vercel.app).

- `/` — the current site (Next.js, deployed on Vercel). See `CLAUDE.md` for the design decisions.
- `design/` — the approved prototype and mockups the site is built from.
- `legacy/` — earlier versions, kept for reference and not deployed:
  - `coming-soon/` — the first static "coming soon" page.
  - `react-site/` — the Create React App site that was live until the rebuild.
